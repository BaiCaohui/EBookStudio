# EBookStudio 使用说明

EBookStudio（解决方案名 EbookToolSuite）是一个 Windows 桌面电子书工具套件：**书库管理 + 阅读器 + 格式转换 + EPUB/TXT/CBZ 编辑 + EPUB 校验 + 阅读统计 + 备份还原**。

所有书库、配置、缓存、备份与统计都保存在本机的数据目录里（默认就是程序目录下的 `Data\`），程序本身不联网、不上传任何数据。整个程序目录可以直接拷到 U 盘或另一台电脑继续用。

当前版本：**1.0.0**（2026-10-21）。

本文件同时是发布包自带的说明文档：发布出来的 `publish\slim\`（精简发布）与 `publish\full\`（全量发布）里都会有一份同样的 `README.md`。

## 1. 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / Windows 11，**64 位（x64）** |
| .NET 运行时 | **不需要单独安装**。两种发布包都是自包含（self-contained）发布，自带 .NET 10 运行时。只有用 `-FrameworkDependent` 参数自己打「依赖运行时」包时，才需要机器上装 .NET 10 Desktop Runtime。 |
| WebView2 运行时 | 阅读 EPUB、TXT 与「可视编辑章节」依赖它。Windows 11 与多数 Windows 10 已随 Edge 自带常青版；若缺失，见[第 15 节](#15-发布包缺失的文件去哪下载)。 |
| 磁盘 | 精简发布约 350 MB、全量发布约 1 GB（见第 14 节实测值）；书库、缓存、备份另算。程序目录必须**可写**（数据默认放在程序目录的 `Data\`）。 |
| 内存 | 无硬性下限；设置里把「转换并发数」调到大于 1 时可能内存不足，默认 1。 |
| 网络 | 运行期不需要联网。只有你手动去下载外部工具时才需要浏览器。 |
| 权限 | 不需要管理员权限；不要装在 `C:\Program Files` 这类只读目录（数据目录会退到 `%LOCALAPPDATA%`，见第 13 节）。 |

发布包里的 `runtimes\`、`*.dll`、`Assets\`、`zh-Hans\` 都是程序运行所需文件，**不要单独移动或删除**；要移动就整个文件夹一起移动。

## 2. 启动与首次运行

1. 打开发布包文件夹（`publish\slim\` 或 `publish\full\`）；
2. 双击 **`EBookStudio.exe`**；
3. 首次启动（数据目录里既没有 `Config.json` 也没有 `Library.db`）会自动弹出**首次运行向导**，共 4 步：
   - 第 1 步：欢迎，并说明数据目录默认在程序目录的 `Data\`（可整体拷走）；
   - 第 2 步：选择数据目录，给出剩余空间提示（预计占用约 3 GB；低于预计占用不允许继续，低于 10 GB 会提醒）；
   - 第 3 步：检查外部工具（Calibre / Java / EpubCheck / WebView2），缺失项给出修复指引；
   - 第 4 步：完成，可选「导入书籍」或「先看看空书库」。
4. 所有步骤都可以跳过；**缺任何外部工具都不会导致启动失败**，只会禁用对应功能。

主界面：

- 左侧导航：**书库 / 转换队列 / 活动中心 / 统计 / 备份与还原 / 设置**，以及默认隐藏的 **诊断**（用命令行 `--debug-ui` 或配置 `ui.showDiagnostics=true` 打开）；
- 左侧栏可折叠（240 → 48 像素；窗口宽度小于 900 时自动折叠，手动折叠后不会被自动逻辑覆盖）；
- 顶部菜单只有三组：**文件 / 工具 / 帮助**；
- 状态栏右侧常驻「工具健康」指示灯：全部必需工具就绪为绿色并显示 `工具 N/N`，否则显示缺失项名称，悬停可看逐工具状态；
- 窗口位置、大小、最大化状态与最后停留页面会记住（左栏折叠状态不持久化）。

## 3. 支持的文件格式

程序内部有 7 种格式枚举，但**导入 / 阅读 / 转换 / 编辑的实际能力并不相同**，以下表为准（✅ 支持，❌ 不支持，⚠ 有条件）。

| 格式 | 扩展名 | 导入书库 | 阅读 | 作为转换源 | 作为转换目标 | 编辑 |
|---|---|---|---|---|---|---|
| EPUB | `.epub` | ✅ | ✅ 直接读（WebView2 渲染） | → MOBI / PDF / TXT / EPUB（净化） | 由 TXT / MOBI / AZW3 / PDF / CBZ / FB2 转入 | ✅ 书籍信息 + 封面 + 章节结构 |
| MOBI | `.mobi`、`.azw` | ✅ | ✅ 打开时后台转成 EPUB 再读（**需要 Calibre**） | → EPUB | ❌ | ❌ |
| AZW3 | `.azw3` | ✅ | ✅ 打开时后台转成 EPUB 再读（**需要 Calibre**） | → EPUB | ❌ | ❌（可用「净化」覆盖源文件） |
| PDF | `.pdf` | ✅ | ✅ 直接读（pdfium 自绘渲染） | → EPUB | ❌ | ❌ |
| TXT | `.txt` | ✅ | ✅ 直接读（自动识别编码 + 自动分章） | → EPUB / MOBI / AZW3 | ❌ | ✅ 全文编辑器 |
| CBZ | `.cbz` | ✅ | ✅ 按页读图 | → EPUB | ❌ | ✅ 书籍信息 + 图片顺序（就地重打包） |
| CBR | `.cbr` | ✅ | ✅ 按页读图（与 CBZ 同一套） | → EPUB | ❌ | ❌（CBR 是 rar，重打包会变成 zip，等于换格式） |
| FB2 | `.fb2` | ⚠ 文件选择器里有，但导入流水线没有 FB2 探测分支，实际会导入失败 | ❌ | → EPUB（前提是先能入库） | ❌ | ❌ |

补充说明：

- 导入文件选择器支持 9 个扩展名：`.epub .mobi .azw .azw3 .pdf .txt .cbz .cbr .fb2`；
- 可打包成 CBZ 的图片：`.jpg .jpeg .png .webp .bmp .gif .avif`（不含 tiff / heic）；
- TXT 的编码下拉在运行时会实际尝试 40+ 种编码（UTF-8、UTF-8-BOM、UTF-16/32、GB2312、GBK、GB18030、Big5、ShiftJIS、EUC-JP/KR、ISO-8859 系列、Windows-125x、KOI8 等），试不出来的不显示；编码按书记忆；
- MOBI/AZW3 的「转 EPUB 后阅读」产物放在 `Data\Cache\Reader\`，不会在书库里凭空多出一个 EPUB 格式记录。

## 4. 书库

### 4.1 导入

导入入口共有 4 类，全部走同一条导入队列与同一条导入流水线：

1. **文件 → 导入文件...**（可多选）；
2. **文件 → 导入文件夹...**（递归扫描子目录）；
3. **书库页工具栏的「导入文件」「导入文件夹」**；
4. **把文件或文件夹拖到主窗口任意位置**（整窗蒙版提示「添加到书库」，松开即导入；导入进行中不接收）。

另外，首次运行向导第 4 步的「导入书籍」、以及「打包图片文件夹为 CBZ」保存后的「导入书库」也复用同一套流程。

导入队列窗口：

- 标题「导入」，表格列：文件 / 状态 / 说明；
- 按钮「暂停(_P)」「取消(_C)」「关闭」；
- 队列单线程串行执行；暂停/取消都是**完成当前这本后停**；
- 单本状态：排队 / 正在导入 / 完成 / 已取消；单本结果分 8 种：已导入 / 重复 / EPUB 无效 / 有 DRM / 格式不支持 / 源文件读不出 / 已取消 / 失败；
- 扫描阶段会显示「正在扫描...」「正在展开选择并预检重复...」；扫描用显式栈遍历，某个目录读不到只记账、不中断整批，跳过符号链接/联接点防目录环，按路径去重；
- 导入顺序：探测 → 算指纹 → 查重 → 复制到暂存 → 移入正式区 → 生成封面 → 写库；任何一步失败都会清掉前序产物；
- 封面：EPUB 取 OPF 封面，PDF 用 pdfium 渲染第 1 页，CBZ 取第 1 页；生成大图（长边 1200）与缩略图（宽 320）两档；封面失败不阻塞导入（用占位图）；
- 元数据：EPUB 读 OPF；TXT / MOBI / AZW3 / PDF 没有 OPF，用文件名顶上；CBZ 读包内 `ComicInfo.xml`（没有就用文件名，作者取 `Writer ?? Penciller`）；
- DRM：按加密算法与覆盖对象分级判断（字体混淆不算 DRM）；
- 「宽松兜底读入」的书会标 `Damaged`，卡片右上角显示「未校验」，详情里多一行「校验：未通过严格校验（宽松读入）」。

### 4.2 重复处理

**导入时的重复**（预检：快速指纹 → 查库 → 全文件 SHA256 确证）：

一次弹一个对话框处理整批，四个按钮：

| 按钮 | 行为 |
|---|---|
| 「跳过全部重复」（默认） | 重复书不入库，记进批次备注 |
| 「全部都导入」 | 当新书再导入一份 |
| 「逐项决定」 | 每本单独询问 |
| 「替换」 | 用新文件替换库里那本 |

对话框表格列：文件 / 情况。

**书库级重复检测**（工具栏「重复检测」）：

- 说明：「按书名、作者、格式分组，再对候选算全文件哈希确证。合并只是把多余的那几本标为副本并从书库隐藏，文件一个都不删。」；
- 按钮：「开始扫描」「关闭」「保留这本」「忽略这组」；
- 每组的建议、数量、体积、哈希判定、成员列表（书名 / 格式 / 大小 / 加入时间 / 哈希）；
- 被标为副本的书不出现在书库列表里，但**文件一个都不删**。

### 4.3 卡片、视图与角标

网格视图卡片自上而下：封面（3:4）、书名（最多 2 行）、作者；四角与边缘还有：

- 左下「格式角标」：显示这本书拥有的**全部格式**（MOBI/AZW3 以 EPUB 形态阅读时，最前面会额外标 EPUB）；
- 右上「未校验」（仅宽松读入的书）；
- 左上阅读状态角标：未读（灰）/ 在读（强调色）/ 已读完（绿）/ 弃读（红），悬停显示完整状态；
- 封面底部 3 像素进度条；
- 右下批量勾选标记；
- 正中文件状态角标：正常 / 已删除（红）/ 已修改（黄）。

视图：

- **网格视图**：按行虚拟化，行内横向排卡片；
- **列表视图**：列有封面、书名、作者、格式、大小、进度、状态（含文件状态小字）、加入时间；表头「书名 / 作者 / 大小 / 加入时间」可点击排序；
- 工具栏按钮在两种视图间切换，文案跟着「点了会切到哪个视图」；默认视图也能在设置里改；
- 封面尺寸三档（小 120×160 / 中 150×200 默认 / 大 190×253），卡片宽度与封面高度随之变化。

### 4.4 搜索、筛选、排序

- 顶栏搜索框只在书库页出现：输入后 200 ms 防抖搜索；`Ctrl+F` 聚焦并全选；`Esc` 清空并退出焦点；`Enter` 立即搜索（不等防抖）；右侧有清空按钮；
- 工具栏显示命中数「共 N 本」；
- 筛选条：格式（全部 / EPUB / MOBI / AZW3 / PDF / TXT / CBZ / FB2）、状态（全部 / 未读 / 在读 / 已读完 / 弃读）、排序（6 项）、「只看有封面」；
- 已选条件以 chips 展示，点一下去掉；「重置筛选」把格式/状态/只看有封面恢复默认（不影响搜索关键词）；
- 排序 6 项：标题 A–Z、标题 Z–A、作者 A–Z、最近加入、最近阅读、文件大小；
- 搜索词、筛选、排序都持久化在 `Config.json`，重启后保持；
- 书库**没有「按作者/系列分组」功能**。

批量模式：

- 「批量选择 / 退出批量选择」「全选」「清空」「已选 N 本」「批量转换」「删除选中的 N 本」；
- 进入批量模式后单击卡片即勾选。

### 4.5 全文搜索

- 入口：书库工具栏「全文搜索」（批量模式下不可用）；
- 浮层：搜索框（回车即搜、`Esc` 关闭）、范围提示（「只搜这本」/「搜全部」）、按书分组的结果、命中词加粗高亮、底部状态文字；
- 点一行结果会打开这本书的对应章节并高亮关键词；
- 索引范围：EPUB（按 spine 顺序抽纯文本）、TXT（按分章结果）、PDF（pdfium 文本层）；漫画与 MOBI/AZW3 不建索引（标记为 `Unsupported`）；
- 索引切片 800 字；导入成功后自动入队建索引（不阻塞导入），启动时续建中断的索引；**没有手动触发重建索引的入口**；
- 状态栏显示「正文索引中 N/M（失败 N）：书名」。

### 4.6 书籍详情（浮层）

点卡片/行或右键「查看详情」打开详情浮层（不是独立页面，返回时网格滚动位置保持）：

- 字段行（空值不占位）：译者、出版社、出版日期、语言、ISBN、系列（`系列 #序号`）、字数、章节、阅读状态、校验（仅宽松读入的书显示）；
- 简介区（最多 120 高度）；
- 逐格式行：每个格式一行，显示大小；MOBI/AZW3 行会注明「该格式不支持阅读，已自动转换为 EPUB 格式」；
- 底部按钮：**阅读、转换、编辑、删除、返回**；
- 右侧小字显示「当前阅读格式」；
- 「文件状态」条：显示缺失/被外部修改的文字 + 「接受改动」（仅被外部修改时出现，把库里的体积、修改时间、指纹更新成磁盘现状，不重新解析元数据）；
- 「已无格式」条：移除最后一个格式后出现，附「移除该格式」。

### 4.7 多格式共存：当前阅读格式、切换、移除

- 一本书可以同时拥有多个格式（转换产物会登记进书库）；
- 「切换此格式」按钮只在「这一行不是当前格式 + 真能读」时出现；切换后点「阅读」打开的就是它，阅读进度会换算到对应位置；
- 「移除该格式」只在**文件已经被删**的格式行出现：只删库里的格式记录，不删任何文件，阅读进度与状态不受影响；
- 缺失/被外部修改的格式：卡片中央角标提示，工具栏汇总「文件扫描结论」。

### 4.8 右键菜单与阅读状态

卡片右键菜单（共享实例，打开时绑定到被右键的那本）：

| 菜单项 | 行为 |
|---|---|
| 查看详情 | 打开详情浮层 |
| 转换格式 | 打开转换窗口 |
| 编辑书籍 | EPUB → 书籍编辑器；CBZ → CBZ 编辑；TXT → 全文编辑器 |
| 标记为 ▸ 未读 / 在读 / 已读完 / 弃读 | 当前状态打勾 |
| 删除 | 二次确认后删除 |

阅读状态除了手动「标记为」，还会自动维护：保存的进度落在书的最末尾 → 已读完；有进度且当前未读/弃读 → 在读；已读完不会被读回去；弃读可被重新读回在读。

### 4.9 删除

- 顺序：**先删库记录，再删文件**（库记录是主契约）；文件删不掉只记警告并汇报；
- 一并清理：各格式文件、阅读缓存目录、正式区书目目录、两档封面；
- 确认框默认按钮是「取消」，文案含书名（多本列出前 10 本 + 总数）与「删除后无法撤销。」；
- 结果只在「有残留文件 / 有删除失败」时弹；
- **没有 Delete 键删除**的快捷键，只有右键菜单与批量模式按钮。

### 4.10 外部改动监控

- 文件系统监听（`FileSystemWatcher`）只当**提示**，不是判定依据；防抖 5 秒；
- 真正的判定靠全量扫描：比较大小与修改时间（2 秒容差，兼容 FAT/exFAT），并发 8，得出正常 / 缺失 / 被外部修改；
- 设置项「自动扫描书库目录变化」（默认开）：开启后目录变化会提示重新扫描，文案明确「只是提示」；
- 书库页「刷新」按钮手动重载。

## 5. 阅读器

### 5.1 打开方式

- 「阅读」按钮、详情浮层「阅读」、双击卡片后在详情里点「阅读」、统计页「最近在读」点整行，都会打开阅读窗口；
- 阅读窗口是**独立顶层窗口**（不设 Owner：主窗口最小化不会把它一起收走；关主窗口时会显式关掉所有阅读窗口）；
- 可以同时打开多个阅读窗口；
- 从全文搜索跳进来时，会带上起始章号与要高亮的搜索词；
- 设置「启动时打开上次读的那本书」（默认关）：开启后启动会直接打开上次读的书并从上次位置继续。

### 5.2 EPUB / TXT 阅读

- EPUB 用 WebView2 渲染，正文在 iframe 里；打开只解压 + 解析 OPF，**章节翻到才物化**；
- TXT 打开时自动识别编码、按分章规则切章（`第X章/节/回`、`Chapter/Part/Prologue/Epilogue`、`【第X章】`、`卷X`、纯数字编号行、`番外/楔子/尾声`；都切不出就按 3000 字硬切，保证一定能读）；
- 工具栏（`左上 → 右`）：
  - 上一章 / 下一章；
  - 目录（快捷键 `T`）：目录列表 + 「编辑目录」（打开书籍信息与目录编辑页，保存后目录自动刷新）+「关闭」；
  - 书签（`Ctrl+B`）/ 笔记（书签与笔记面板）；
  - 抬头显示章节标题与「第 [x]/N 章　第 [y]/M 页」，两个数字都是**可输入跳转**框（Enter 或失焦跳转）；
  - 阅读主题下拉：白 / 米黄 / 深灰 / **纯黑** / 护眼绿 / 自定义（自定义可设正文底色、字色、链接色）；
  - TXT 专用编码下拉；
  - 「Aa」字体与排版面板；「分页」切换分页/滚动（`Ctrl+M`）；「编辑本章」；「查找替换」；
  - 跳全书百分比面板（`Ctrl+G`：滑块 + 跳转）；
  - 状态栏：上一章 / 「第 x / y 章」 / 「全书 N%」 / 提示 / 下一章。
- 选中文字会弹出操作条：高亮 / 下划线 / 波浪线 / 删除线 / 加笔记 / 复制 / 章内查找；右键也弹这一条（WebView2 自带右键菜单已关闭）；
- 章内查找（`Ctrl+F`）：查找框 + 「第 N / M 个」+ 上一个 / 下一个 / 关闭；
- 全书查找替换：范围「当前章节 / 全书」、可勾「正则模式」「区分大小写」、上一个/下一个、替换、全部替换、「撤销上一次替换」；全部替换前弹「替换预览」确认框（取消则一个字节都不改）。

### 5.3 PDF 阅读（pdfium 自绘）

- 能力：总页数、按页渲染（支持旋转、主题背景、长边上限、20 页 LRU 内存缓存）、读单页文本层（纯文本 + 逐字符框）、读全书文本、读目录（书签树拍平）；
- 页码输入跳转（精确）、缩小 / 放大（`Ctrl+-` / `Ctrl+=`，`Ctrl+0` 复位）、适应页面、适应宽度、旋转（0°/90°/180°/270°）、单页 ↔ 滚动、单页 ↔ 双页、日漫模式（右到左）、PDF 内文本搜索（命中高亮 + 上一个/下一个）、全屏（`F11`，退出 `Esc`）、「外部打开」（交给系统默认程序）；
- 加密 PDF：最多询问 3 次密码；密码只在内存，不落盘；试满可改用系统默认程序打开；
- 打开失败会区分原因（未给密码 / 文件损坏 / 缺 pdfium），错误层提供「用系统默认程序打开」兜底；
- 页位图只在内存里（预加载页数 + 8，夹在 24–64 之间），`Data\Cache\Pages\` 刻意不创建、不落盘；
- 预加载页数在设置页调（1–1000，默认 10），PDF 与漫画共用。

### 5.4 CBZ / CBR 漫画阅读

- 按页读图（内存 JPEG，不落盘），页数按包里图片条目数算；
- 三种版式：单页、滚动（连续）、双页并排；另有**日漫右到左**（RTL 下左右键方向相反）；
- 键盘：PageUp / PageDown、← / →、空格、Home / End；
- 漫画**没有文字层**：`Ctrl+F` 会直接提示「漫画没有文字层」，不会打开一个永远 0 结果的查找框；
- CBR（rar）与 CBZ 走同一条读图路径。

### 5.5 标记、书签与笔记

- 标记样式 7 种：荧光、下划线、波浪线、删除线、虚线、背景色、字体色；
- 颜色 14 个：红、红橙、橙、橙黄、黄、黄绿、绿、绿青、青、青蓝、蓝、蓝紫、紫、灰；
- 标记**只套显示层，不改原文件**（EPUB 加 `<mark>`，PDF 给字符框加 class）；
- 笔记面板：显示样式名与时间、14 色色点、7 种样式、引文、备注输入框、删除笔记、保存（`Ctrl+Enter` 保存 / `Esc` 关闭）；
- 书签与笔记面板：书签页「添加书签」，两页都有「导出」——导出为 Markdown，落到 `Data\Exports\书签笔记-yyyyMMdd-HHmmss.md`；关闭面板用「关闭」或 `Esc`。

### 5.6 阅读进度、状态与跨格式定位

- 进度保存：最新位置先攒内存，**1.5 秒防抖**后落盘；关窗/退出强制 Flush；失败只记警告，不影响阅读；
- 进度内容：章号、页号、总页数、章内位置、文字指纹、百分比、来源格式；
- 跨版式（文本 ↔ 固定版式）：按已读百分比换算章/页；
- 跨文本格式（EPUB ↔ TXT ↔ MOBI/AZW3）：先按**文字指纹**在目标书里找章（最多翻 24 章），找不到再退回百分比估章；
- 同版式继续读用精确恢复（章号 / 页码），不做百分比换算。

### 5.7 其它行为

- 全屏：窗口无边框最大化，退出时原样恢复；
- 「编辑本章」：EPUB 打开可视编辑窗口（改的是工作区副本，绝不碰原书），TXT 打开全文编辑器并定位到当前章；保存后只重载阅读缓存里的当前章；
- 「编辑目录」：打开 EPUB 书籍编辑器，保存后目录抽屉与书籍信息自动刷新；
- 关阅读窗口后书库自动刷新进度角标（先把进度落盘再通知）；
- 一次阅读会话 = 一条统计记录；心跳最多 1 分钟一次，两次事件间隔 > 5 分钟视为挂机并另起一条会话（详见第 8 节）。

## 6. 格式转换

转换由 Calibre 执行；「不换格式、只净化」走 `ebook-polish`；「图片文件夹 → CBZ」走程序自研打包器（Calibre 没有 CBZ 输出插件）。

### 6.1 单本转换

入口：书库页工具栏「转换」、卡片右键「转换格式」、书籍详情「转换」、菜单「文件 → 转换格式...」（菜单项在未选中书时置灰）。

窗口「转换格式」包含：

- 源格式（这本书有多个格式时可切换源）；
- 目标格式（只列出转换矩阵允许、且这本书还没有的格式；另加「不换格式，只优化（EPUB/AZW3）」一项）；
- 转换模板（每个目标格式一组模板；「不换格式只优化」必须选一个具体模板）；
- 输出位置（只读展示；默认写进这本书的 Library 目录，与原件同目录）；
- 「高级参数（可选，谨慎使用）」折叠区：每行一个参数（如 `--base-font-size 20`），**先过 Calibre 白名单，不被支持的一律拒绝执行**；
- 提示条：点「加入队列」后任务排进转换队列，进度与结果到「转换队列」页看；
- 按钮：另存为模板、删除模板、取消、加入队列。

默认目标格式由设置「转换 → 默认输出格式」决定（EPUB / MOBI / PDF / TXT 四项）。

### 6.2 转换矩阵

只转换矩阵里列出的链路，未列出的直接拒绝，不做「试试看」。

| 源 \ 目标 | EPUB | MOBI | AZW3 | PDF | TXT |
|---|---|---|---|---|---|
| EPUB | ✅（EPUB→EPUB 即「净化」） | ✅ | ❌ | ✅ | ✅ |
| TXT | ✅ | ✅ | ✅ | ❌ | ❌ |
| MOBI | ✅ | ❌ | ❌ | ❌ | ❌ |
| AZW3 | ✅ | ❌ | ❌ | ❌ | ❌ |
| PDF | ✅ | ❌ | ❌ | ❌ | ❌ |
| CBZ | ✅ | ❌ | ❌ | ❌ | ❌ |
| FB2 | ✅（前提是能入库） | ❌ | ❌ | ❌ | ❌ |

其它规则：

- 自动挑源文件的优先顺序：EPUB → TXT → FB2 → MOBI → AZW3 → PDF → CBZ；
- 「不换格式、只净化」只吃 EPUB / AZW3（不支持 KEPUB），产物**覆盖源文件**（先备份）；
- 同一本书已经有目标格式时会被拒绝，提示先移除该格式或换一个输出格式。

### 6.3 批量转换

- 入口：书库批量模式「批量转换」（把已勾选的书一次入队）；
- 窗口「批量转换」：目标格式、转换模板、提示 + 取消 / 加入队列；
- 逐本入队失败不会拖垮整批（逐条记日志，最后汇总弹框）。

### 6.4 转换队列页

- 汇总文案 + 工具栏「全部取消」「清除已完成」「刷新」；
- 每个任务卡片：书名、格式流（源 → 目标）、详情、状态、进度条（百分比或不确定）、已耗时；
- 右侧操作：「查看日志」「跳转」（资源管理器定位输出）「导出」（另存到别处，原文件不动）「取消」「重试」「移除」；
- 「跳转」「导出」只在真的产出成功且文件还在时可用；
- 失败任务有错误条 +「重试」；
- 空态：「转换队列是空的 / 在书库里选中一本书点「转换」，或批量选择后点「批量转换」，任务就会排到这里。」；
- 任务状态：排队中 / 运行中 / 已完成 / 失败 / 已取消 / 等待重试。

### 6.5 模板

6 个内置模板（代码是唯一来源）：

1. `mobile-readable`「手机 / 平板易读 (EPUB)」；
2. `a4-print`「A4 打印 / 电脑阅读 (PDF)」；
3. `plain-utf8`「纯文本归档 (TXT)」；
4. `comic-zip`「漫画打包 (CBZ)」；
5. `kindle-best`「MOBI（备选）」；
6. `polish-only`「仅净化，不换格式」。

每个参数都带中文说明；`--extra-css` 用占位符 `{EyeCareCss}` 运行时替换成随程序分发的 `Assets\Conversion\eye-care.css`。

用户模板：转换窗里「另存为模板 / 删除模板」，存进数据库（`is_builtin=0`），内置模板不受影响；设置页不重复提供模板管理。默认模板按目标格式另存（`conversion.defaultTemplates.*`）。

### 6.6 取消、重试、优先级、崩溃恢复

- 重试策略：磁盘满 / 参数错 / 文件不存在 / 损坏 / 取消**不重试**；超时最多再给 1 次；进程崩溃 / 退出码非 0 / 无产物只有「像是被文件占用」才重试；退避 5s/10s/20s；默认最多重试 3 次；
- 优先级：阅读缓存转换用 `Priority=1000` 插队，普通批量用 0；
- 崩溃恢复：启动时把上次残留的「运行中 / 等待重试」归位为排队中并续跑（Calibre 无断点续传，从头重转）；
- 磁盘预检：转换前按「输入大小 × 3 + 200 MB 余量」估算，空间不够直接拒绝；
- 并发数（1–4，默认 1）、超时（1–1440 分钟，默认 60）在设置页改；并发 > 1 可能内存不足，且重启后生效。

### 6.7 转换产物与元数据

- 转换产物登记进书库，成为这本书的另一个格式（与原件同目录）；
- 阅读缓存用的中间产物（MOBI/AZW3 → EPUB）不登记格式，不会让书库凭空多一个 EPUB；
- 「净化」就地替换后会更新该格式的体积与指纹（旧全量哈希作废）；
- **转换链路不跑 EpubCheck**（EpubCheck 只用于 EPUB 编辑保存，见第 7 节）。

## 7. 编辑（EPUB / TXT / CBZ）

可编辑格式只有三种：**EPUB、CBZ、TXT**。其它格式点「编辑」会提示「这本书没有可编辑的文件（目前能编辑 EPUB、CBZ 与 TXT）。」

编辑入口：书库页工具栏「编辑」、卡片右键「编辑书籍」、书籍详情「编辑」、阅读器「编辑本章 / 编辑目录」。

同一本书只开一个编辑窗口（已开则前置）；EPUB 编辑器与 TXT 编辑器各自最多同时开 2 个。

### 7.1 EPUB 书籍信息编辑窗

窗口标题随书名实时变，抬头显示被编辑文件的路径；三栏布局（章节树 / 封面 / 元数据），两条可拖分栏。

元数据字段 12 个：

1. 书名；
2. 副标题（仅 EPUB3 可用；EPUB2 里禁用并说明「副标题是 EPUB3 的 refines 写法」）；
3. 作者（多个用「、」分隔；EPUB2 写 `opf:role`，EPUB3 写 refines）；
4. 系列（写 `calibre:series`）；
5. 系列序号（写 `calibre:series_index`）；
6. 语言；
7. ISBN；
8. 出版社；
9. 出版日期（格式 `2024-05-01`，留空 = 不写）；
10. 简介（多行）；
11. 标签（多个用「、」分隔，写 `dc:subject`）；
12. 评分（未评分 / ★ / ★★ / ★★★ / ★★★★ / ★★★★★，写 `calibre:rating`，0–5 星 ↔ 0–10）。

封面区：

- 「替换封面...」（支持 JPG / PNG / WebP，自动裁到最大边 1600 的 JPEG）；
- 没有封面时显示「（没有封面）」。

底部按钮：

- **保存**：写回 OPF → 打包 → 结构自检 → 原子替换原文件（保存前依 EpubCheck 门禁与还原点，见 7.7）；
- **放弃修改并关闭**：原文件一个字节都不动；
- **关闭**。

### 7.2 章节结构编辑

章节树以 **spine 为权威**，标题/层级从目录补；目录里没有的章节提示「目录里没有这一章（标题按文件名显示）」。

操作按钮：

| 控件 | 作用 |
|---|---|
| 重命名 + 输入框 | 只改目录文字，不动文件名 |
| 上移 / 下移 | 改 spine 顺序 + 目录顶层对齐 |
| 升一级 / 降一级 | 只改目录层级，正文与文件名都不动 |
| 可视编辑 | 打开所见即所得编辑器 |
| 编辑源码 | 打开 XHTML 源码编辑器 |
| 资源检查 | 查悬空引用 / 孤儿资源 |
| 拆分点下拉 + 拆分章节 | 在第 N 个正文块前切开，后半另存新章紧跟其后 |
| 合并下一章 | 把下一章并进当前章 |
| 删除 | spine + manifest + 目录 + 文件进暂存区 |
| 新增空章 | 在指定位置插空章 |
| 导入文件... | 从 `.xhtml / .html / .txt` 导入一章 |
| 回到会话开始 | 丢掉工作区、用原书重开（原文件从未动过） |
| 状态行 | 显示最近一次操作结果 |

所有章节操作**只改工作区**，点主窗口【保存】才写进书里。

### 7.3 章节源码编辑器

- 标题「编辑章节源码」；
- 章节下拉 + 「保存到工作区」「重新载入」；
- AvalonEdit：Consolas 13、行号、XML 语法高亮、不折行；
- 「保存到工作区」**先做 XML 语法检查，通过才写回工作区**（写进书还要在主窗点保存）；
- 未保存修改时有内联提示条：「保存 / 放弃修改 / 取消」。

### 7.4 章节可视编辑器

与阅读器同一套 WebView2 渲染栈，所见即所得。

底部历史栏：「历史」下拉 + 「还原」「刷新」，列出全量基线 / 保存前 / 全部替换前 / 还原前自动快照。

功能区：

- 编辑：清格式、撤销（`Ctrl+Z`）、重做（`Ctrl+Y`）；
- 字体：加粗（`Ctrl+B`）、斜体（`Ctrl+I`）、下划线（`Ctrl+U`）、删除线；段落样式下拉（正文 / 标题 1–4 / 引用）；字号下拉（80% / 90% / 100% / 110% / 125% / 150% / 200%，相对字号随读者字号缩放）；
- 段落：无序/有序列表、左/居中/右/两端对齐、减少/增加缩进；
- 图片：插入、替换（选中图）、删除（选中图）；
- 表格：行列插入；行+上/行+下/删行/列+左/列+右/删列/合并右/拆分/选行/选列/删表格；列宽/行高/表宽数值应用；
- 源码视图：切到这一章的源码；
- 「保存到工作区」（写进书还要在主窗点保存）。

自动修正：保存前发现「引用了不存在的资源 / manifest 未声明」等问题会弹确认框，确认后**先建还原点再改工作区**。

### 7.5 资源检查

两栏：

- 「悬空引用（引用了不存在的文件）」标红；
- 「孤儿资源（在 manifest 里但没人引用）」标黄。

按钮：「重新扫描」「定位到源文件」「移除该引用」「删除孤儿」「关闭」。没有问题时摘要追加「：没问题」。删除孤儿前会先建快照。

### 7.6 阅读器内查找替换

- 范围：当前章节 / 全书；
- 选项：正则模式、区分大小写；
- 操作：上一个 / 下一个、替换、全部替换、「撤销上一次替换」、关闭；
- 全部替换前弹「替换预览」确认框，确认后只写工作区副本，取消则一个字节都不改。

### 7.7 保存链路、EpubCheck 与还原点

EPUB 保存链路：

1. 打包到 `{目标}.ets-stage.epub`；
2. 跑 **EpubCheck 5.4.0**（`{java} -jar {jar} "{input}" --json "{out}" --quiet`）：
   - 0 error：静默通过；
   - 只有 warning：放行并提示；
   - 有 error：阻止保存，但给「仍然保存（不推荐）」；
   - 校验超时 / 工具跑挂：不硬拦；
   - JRE 或 EpubCheck 没装：直接放行并提示「未安装校验工具（JRE 或 EpubCheck 缺失），已跳过校验。」；
3. 打包器自身结构自检（不依赖 EpubCheck）：mimetype 必须是第一条、STORED、内容精确、不重复等；
4. 先建还原点；
5. 原子替换原文件；失败按还原点恢复。

历史与备份机制：

| 机制 | 位置 / 范围 |
|---|---|
| 工作区快照 | `{工作区}\.snapshots\{id}\`（manifest.json + files/），打包时排除，绝不进 EPUB |
| 快照类型 | `initial`（全量基线）/ `save` / `replace-before` / `delete-before` / `restore` / `manual` |
| 快照保留 | 保存前留最近 10 份；替换前/删除前/还原前各 1 份；手动标记 5 份；全量基线永远保留 |
| 还原点（书级） | `Data\Backup\RestorePoints\{pointId}\` + manifest.json；默认总上限 1 GB、每本书最多 5 份 |
| 还原点类型 | `save` / `restore`（反向还原点）/ `batch` / `autofix` |
| 单文件备份 | `Data\Backup\Files\{bookId}\{yyyyMMddHHmmss}_{name}.bak` |
| 操作日志 | `operation_log`：保存 / 强制保存 / 还原 / 备份清理 / 导入 / 换封面 / autofix |

### 7.9 CBZ 打包前编辑（文件 → 打包图片文件夹为 CBZ...）

1. 选一个图片文件夹（程序递归扫描）；
2. 打开「**编辑 CBZ 信息**」窗口：左侧「图片顺序」、右侧「书籍信息」，可拖分栏；
3. 图片列表按包内顺序从上到下排列：
   - 「↑ 上移」「↓ 下移」「重命名」（改包内文件名主干，扩展名固定不变）、行内 ✎、双击预览、**拖拽排序**、`F2` 重命名；
   - 改名/调序后列表立即按新顺序重排；调序后会按新顺序**重编号包内文件名**；
   - 双击图片名打开预览窗（灯箱式深色底、滚轮缩放、「适合窗口」、「关闭（Esc）」）；
4. 书籍信息 = **37 个 ComicInfo 字段**，分 6 组：

| 组 | 字段 |
|---|---|
| 基本信息（8） | 标题、系列、序号、计数、卷、副系列、副序号、副计数 |
| 创作者（7） | 编剧、线稿、勾线、上色、嵌字、封面、编辑 |
| 出版（5） | 出版社、出版品牌、出版年、月、日 |
| 分类与内容（8） | 类型、标签、角色、团队、地点、故事线、系列组、分级 |
| 说明与来源（7） | 简介、备注、网址、语言、格式、扫描信息、ISBN |
| 其它（2 + 自动） | 黑白（三态）、阅读方向（三态）、页数（只读自动） |

日期校验：年 1000–2999、月 1–12、日 1–31，可只填年。全部留空则不写 `ComicInfo.xml`（只有页数的空文件没有意义）。

5. 点「保存」后进入「保存 CBZ」文件对话框；保存成功会问「是否将这本书导入书库？」，选「导入书库」即走标准导入流程（含去重与元数据解析）。

打包规则：`ComicInfo.xml` 作为包内第一个条目、UTF-8 无 BOM；图片用不压缩存储（本身已是压缩格式）；手动调序时用零填充前缀（如 `0001_原文件名.jpg`）表达页序（CBZ 没有页序字段，阅读器按文件名自然序排序）。

### 7.10 书库内 CBZ 就地编辑

- 入口：书库页工具栏「编辑」、卡片右键「编辑书籍」、书籍详情「编辑」，命中的是 CBZ 时；
- 流程：解压到临时工作区 → 读旧 `ComicInfo.xml` → 打开同一个「编辑 CBZ 信息」窗口（保存按钮语义变为覆盖原文件）→ 保存时**先备份原件** → 重新打包 → 原子替换原文件 → 回写书库元数据 → 更新格式基线（避免被扫描报成外部修改）→ 按新的第 1 页重渲封面 → 刷新书库；
- 只支持 CBZ（zip）；CBR（rar）不做就地编辑（重新打包会变成 zip，等于偷换格式）；
- 保存成功提示「已保存并重新打包。」，失败按统一中文错误提示；
- 标题必填：清空会回填原书名。

## 8. 阅读统计

入口：左栏「统计」（`Ctrl+4`）。

- 范围切换：「今日」（默认）/「本周」/「本月」/「全部」；
- 四张指标卡：**阅读时长、连续天数、读完的书数、平均阅读速度**（没有字数数据时显示「—」）；
- 趋势图：「近 14 天阅读时长」自绘条形图（不引图表库；零时长留 2 像素底线；悬停显示「M月d日 · 时长」）；
- 书库构成：
  - 阅读状态分布（未读 / 在读 / 已读完 / 弃读，固定四行）；
  - 格式分布（按文件份数统计，一本多格式各算一次）；
- 「最近在读」：最多 8 本，显示书名、已读百分比、最后阅读时间，**整行可点直接打开阅读窗口**；
- 副标题：「范围：… · 书库共 N 本 · 统计于 HH:mm（数据只在本机统计，不上传）」；
- 空/加载/错误三态；空态有「去书库」按钮；「空」的含义是**从来没读过**（不是「这个范围没数据」）。

统计口径：

- 一次打开 = 一条阅读会话；时长 = `ended_at - started_at`；`ended_at` 是最后一次阅读事件时间（挂机不计时）；
- 心跳最多 1 分钟落库一次；两次事件间隔 > 5 分钟视为挂机，旧会话按最后活动时间收尾、另起一条；
- 时长跨本地日按日拆分；连续天数按本地自然日连续段；读完书数按状态 + 范围内最后阅读；速度 = 字数 ÷ 分钟；
- 删除书时它的阅读会话一起删除（不保留已删书统计）；
- 数据只在本机，不上传。

## 9. 备份、迁移与维护

### 9.1 备份与还原页

入口：左栏「备份与还原」。

- 列表列：时间、类型（保存 / 还原）、书、文件、大小；
- 顶部按钮：「清理超限备份」「还原选中的还原点」；
- 副标题：「共 N 个还原点，占用 X / 上限 Y（每本书最多留 5 份）」；
- 「还原」：二次确认（「当前的版本会先被自动备份成一个新的还原点（反向还原点），所以退回去之后还能再退回来。」）→ 还原 → 提示反向还原点编号；
- 「清理超限备份」：按上限清理最旧的，提示释放量或「没有需要清理的」；
- 上限来自设置「备份 → 大小上限」（默认 1024 MB）；
- 空态文案说明：每次保存书籍时都会自动建一个还原点（放在 `Data\Backup\RestorePoints` 下）。

### 9.2 数据库备份

设置页「备份 → 立即备份」：

1. 先执行 `PRAGMA wal_checkpoint(TRUNCATE)`；
2. 把 `Library.db` 与 `Config.json` 复制到 `Data\Backup\Database\manual-yyyyMMdd-HHmmss\`。

注意：备份的是**数据库与配置**，不含书库正文文件；正文文件靠还原点，或直接拷整个 `Data\`（见第 13 节）。

### 9.3 数据目录迁移向导

入口：设置页「书库 → 更改数据目录…」。

- 标题「更改数据目录」；说明「把书库、配置与备份整体搬到一个新位置。复制完成后会逐文件校验，校验失败或取消都会回滚；迁移完成后需要重启程序才生效。」；
- 显示当前数据目录 + 「打开所在文件夹」+ 占用统计；
- 目标目录：「浏览…」「检查」；可勾「连缓存一起搬（Cache / Temp）」；目标已是数据目录时提供「直接切换到该目录…」；
- 前置检查（动态行，含修复说明）：网络盘 / 可移动盘会被拦下（SQLite 的 WAL 在那些盘上不可靠）；
- 迁移校验：文件数 + 逐文件大小 + 复制后数据库 `PRAGMA integrity_check`；失败回滚且不改指针；
- 完成后可选「立即重启 / 稍后重启」；
- 迁移成功后设置页出现「删除旧数据目录」按钮（旧目录不会自动删）。

### 9.4 首次运行向导

见第 2 节。触发条件：数据目录里既无 `Config.json` 也无 `Library.db`，且 `ui.firstRunCompleted=false`。

### 9.5 活动中心

入口：左栏「活动中心」（`Ctrl+3`）。

- 两个数据源合成一条时间线：`import_batch`（最近 100 批）+ `operation_log`（最近 200 条），按时间倒序；
- 列：时间、来源、结果、备注；
- 来源映射：导入 / 编辑保存 / 强制保存 / 还原 / 备份清理 / 换封面 / autofix；
- 副标题「最近 N 条记录。」；空态「还没有记录」。

### 9.6 诊断页（默认隐藏）

显示方式：命令行 `--debug-ui`，或 `Config.json` 里 `ui.showDiagnostics=true`。

三张卡片：

1. **路径**：程序目录、数据目录、日志目录（数据/日志目录带「打开」按钮）；
2. **工具健康**：工具目录 + 「重新检测」+ 每个工具一行（状态圆点、名称（可选项会标注）、状态、版本、修复提示）；状态文案：正常 / 缺失 / 版本不符 / 探测失败 / 已关闭；
3. **日志（内存缓冲）**：最近 200 行 + 「复制最近 200 行」「打开日志目录」。

「诊断动作」：「触发 UI 线程异常」「触发未观察 Task 异常」（仅用于验证全局异常处理链路，正常使用不要点）。

说明：诊断页**没有「数据完整性检查」**；`PRAGMA integrity_check` 只在数据目录迁移向导里做。

### 9.7 日志与诊断导出

- 日志：`Data\Logs\app-yyyyMMdd.log`，按天滚动，保留 14 份，单文件上限 20 MB，UTF-8 无 BOM；
- 日志级别在设置「高级」里改（Verbose / Debug / Information / Warning / Error / Fatal，重启生效）；
- 内存里另有一份环形缓冲，帮助菜单「复制最近 200 行日志」与诊断页都从它取（日志文件被 Serilog 持有，直接读不方便）；
- 「导出诊断信息」：生成 `Data\Exports\Diagnostics-yyyyMMdd-HHmmss.zip`，内含 `config.json`（脱敏：窗口状态与 paths 隐藏）、`tools/health.json`、`db/schema.json`（表与行数，不含正文）、`system/info.json`（含 WebView2 版本）、最近 3 天日志（≤ 10 MB）。

### 9.8 错误处理

- 三处全局兜底：UI 线程 / 后台线程 / 未观察 Task；UI 线程异常标记为已处理，进程不会因为一个异常直接退出；
- 错误对话框统一中文，包含：「发生了未预期的错误，但程序会继续运行。」+ 人话说明 + 错误码（`ETS-域-四位序号`，域前缀 `ETS-GEN / ETS-LIB / ETS-EDIT / ETS-CONV / ETS-READ`）+ 「完整技术细节已写入日志：日志目录」+ 提示可从「帮助 → 打开日志目录」找到；
- 业务异常统一走 `AppException`（错误码 + 人话 + 技术细节 + 上下文）；
- 应用内对话框统一使用 `AppDialog`，不使用系统裸 MessageBox。

## 13. 数据目录、备份与迁移

### 13.1 数据目录在哪、怎么定位

解析顺序（第一个可用的胜出）：

1. 命令行 `--datadir=<绝对路径>`；
2. 指针文件 `%LOCALAPPDATA%\EbookToolSuite\datadir.txt`；
3. **程序目录下的 `Data\`（默认，绿色便携形态）**；
4. 兜底：`%LOCALAPPDATA%\EbookToolSuite\Data`（程序目录不可写时自动切换，并写指针文件）。

指针文件是定位数据目录的唯一权威（`Config.json` 在数据目录内部，数据目录一旦外置就无法自举定位）；`Config.json` 里的 `paths.dataDir` 只是镜像值。

### 13.2 `Data\` 里有什么

| 路径 | 用途 |
|---|---|
| `Config.json` | 唯一配置文件（设置、窗口状态、上次读的书、迁移镜像等） |
| `Library.db`（+ `-wal` / `-shm`） | SQLite 主库（书、格式、进度、会话、还原点索引等） |
| `Library\{bookId}\` | 书籍文件正式区（导入时复制进来，原文件不动） |
| `CalibreConfig\` | Calibre 配置隔离目录（`CALIBRE_CONFIG_DIRECTORY`） |
| `WebView2Data\` | WebView2 的 `userDataFolder` |
| `Workspaces\{sessionId}\` | EPUB 编辑工作区（含 `.snapshots\`） |
| `Temp\` | 临时文件（启动时清理超过 24 小时的 `.part/.tmp`） |
| `Logs\app-yyyyMMdd.log` | 日志 |
| `Cache\Covers\` | 封面两档（`{id}.jpg` 与 `{id}_t.jpg`） |
| `Cache\Reader\` | MOBI/AZW3 转出的临时 EPUB、TXT 生成物 |
| `Cache\Calibre\` | Calibre 缓存 |
| `Cache\Pages\` | **故意不创建、不写文件**（PDF 页位图只在内存），不要把它当 PDF 缓存目录 |
| `Exports\` | 导出产物（书签笔记 Markdown、诊断 zip） |
| `Backup\Files\{bookId}\` | 单文件备份 |
| `Backup\RestorePoints\{pointId}\` | 还原点（含 manifest.json） |
| `Backup\Database\manual-yyyyMMdd-HHmmss\` | 数据库手动备份 |

### 13.3 绿色便携

- 默认数据目录就是程序目录的 `Data\`，所以**把整个程序目录拷到 U 盘或另一台电脑即可继续用**；
- 阅读器缓存、日志、备份、导出全部在 `Data\` 内；
- 如果程序目录不可写（例如只读介质 / 受保护目录），程序会退到 `%LOCALAPPDATA%\EbookToolSuite\Data` 并写指针文件，避免启动失败。

### 13.4 备份（最省事的办法）

- **直接拷 `Data\` 就是完整备份**：书库文件、数据库、配置、缓存、备份都在里面；
- 只想备份「书目与阅读记录」：用设置「备份 → 立即备份」（`Library.db` + `Config.json`）；
- 想备份「某一本书的某个版本」：用还原点（每次保存书籍时自动建）；
- 恢复：先关闭程序，再用备份的 `Data\` 覆盖现有 `Data\`（或按需还原单个还原点）。

### 13.5 迁移到别的盘

- 推荐用设置页「书库 → 更改数据目录…」向导：复制 → 逐文件校验 → 数据库完整性检查 → 重启生效；失败或取消会回滚且不改指针；
- 迁移完成后旧数据目录保留，可用「删除旧数据目录」按钮清理；
- 手工迁移也可以：先关程序，把整个程序目录（含 `Data\`）拷到新位置再启动；如果只想搬数据目录，请让向导处理指针文件（不要只挪 `Data\` 而不改指针，否则程序仍会找旧位置）。

## 14. 两种发布模式：精简发布与全量发布

发布目录里有两个独立文件夹，**各自是一份完整可运行的发布包**：

## 16. 外部工具与功能可用性

工具清单与版本钉在 `Tools\manifest.json`；工具体检有 5 种状态：正常 / 缺失 / 版本不符 / 探测失败 / 已关闭（可选工具在设置里关掉）。

| 工具 | 必需 | 缺失时影响 |
|---|---|---|
| **Calibre**（`Tools\Calibre Portable\Calibre\`） | ✅ 必需 | 所有换格式转换、净化、「MOBI/AZW3 转 EPUB 后阅读」都不可用；启动后顶部红色横幅说明原因，「转换」窗口的「加入队列」等按钮置灰并给出修复指引；其余功能正常 |

## 17. 从源码构建与发布

```powershell
# 全量编译（0 警告是仓库纪律）
dotnet build EbookToolSuite.sln -c Debug

# 全量测试
dotnet test EbookToolSuite.sln -c Debug --no-build

# 精简发布（主程序 + JRE + EpubCheck，不含 Calibre）
powershell -NoProfile -ExecutionPolicy Bypass -File build\publish.ps1 -OutputDir publish\slim

# 全量发布（再带 Calibre，开箱即用）
powershell -NoProfile -ExecutionPolicy Bypass -File build\publish.ps1 -Full -OutputDir publish\full
```

发布脚本要点：

- 默认输出目录是仓库根的 `publish\`；用 `-OutputDir` 指定两个模式各自的文件夹；
- 发布前会检查发布目录里的 `EBookStudio.exe` 是否在运行（被占用会导致覆盖失败）；
- 输出目录里已有的 `Data\`（书库）与 `Tools\`（工具）会**先挪开、发布完原样放回**，避免「精简模式重发」削掉上次全量发布带的 Calibre；确认要清掉才用 `-Fresh`（慎用，会连数据目录一起清）；
- `README.md` 会自动从仓库根复制进发布包；
- `-FrameworkDependent` 可打「依赖 .NET 10 运行时」的小体积包（自包含以外的另一种选择）；
- 发布包结构（两个模式一致，只有 `Tools\Calibre Portable\` 有无的区别）：

```
publish\slim\ 或 publish\full\
  EBookStudio.exe
  EBookStudio.dll
  EbookToolSuite.*.dll
  *.dll（.NET 运行时、WebView2、SQLite、pdfium、ImageSharp 等）
  runtimes\
  Assets\
  zh-Hans\
  README.md
  Data\             ← 首次运行后自动创建（书库、配置、缓存、日志、备份）
  Tools\
    manifest.json
    JRE\            ← 精简与全量都有
    EpubCheck\      ← 精简与全量都有
    Calibre Portable\  ← 仅全量发布
```

## 19. 已知限制

以下均为当前实现的真实边界（写在这里以免误以为 bug）：

1. **FB2 不能作为书库格式使用**：扩展名在导入白名单与转换矩阵里，但导入流水线没有 FB2 探测分支，实际会导入失败；阅读与编辑也不支持。
2. **精简发布没有 Calibre**，且**没有「指向外部安装」的设置项**：要么把 Calibre 便携版放进 `Tools\Calibre Portable\`，要么用全量发布。
3. **转换不跑 EpubCheck**：校验只发生在 EPUB 编辑保存链路；转换结果的质量由 Calibre 决定。
4. **只有 EPUB / TXT / CBZ 可编辑**：MOBI/AZW3/PDF/FB2 只能阅读或转换（AZW3 可用「净化」覆盖源文件）。
5. **CBR 不能就地编辑**：重打包会变成 zip，等于换格式。
6. **CBZ 就地编辑会重打包**：包里除图片与重新生成的 `ComicInfo.xml` 外的其它条目（例如额外的说明文件）不会保留；压缩包内子目录会被拍平，重名文件加 `(2)` 后缀。
7. **CBZ 重排后阅读进度不重映射**：进度按页索引保存，重排后可能落到别的页。
8. **书库没有分组功能**（只有筛选、排序、搜索）；**统计没有「每本书明细」表**（只有「最近在读」最多 8 本）。
9. **诊断页没有数据完整性检查**；`PRAGMA integrity_check` 只在数据目录迁移向导里执行。
10. **统计不保留已删书的记录**：删书时阅读会话一起删除。
11. **备份不会自动清理**：需要点「清理超限备份」；每本书最多留 5 份还原点。
12. **字体设置只作用于阅读器正文**，不改变程序界面字体。
13. **左栏折叠状态不持久化**（窗口位置/大小/最大化会持久化）。
14. **`Data\Cache\Pages\` 不落盘**：PDF 页位图只在内存。
15. **正文索引没有手动重建入口**（导入后自动建、启动时续建）；漫画与 MOBI/AZW3 不索引正文。
16. **书库「未校验」角标 ≠ EpubCheck 结论**：它表示这本书是「宽松兜底读入」的（`Damaged`）。
